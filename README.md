# MAIA · downloads

Aqui ficam só os instaladores da **MAIA**, a assistente pessoal da Gravidade Zero. O código não fica aqui.

**Para baixar, use a página [minha-maia.vercel.app/baixar](https://minha-maia.vercel.app/baixar)**, que explica a instalação passo a passo. Por enquanto, a MAIA é só para convidados.

Cada versão (em [Releases](https://github.com/Artur-Antunes-1/maia-downloads/releases)) traz:

| Arquivo | Para |
| --- | --- |
| `MAIA-Setup-Windows-x64.exe` | Windows 10 ou 11, 64 bits |
| `MAIA-Mac-AppleSilicon.dmg` | Mac com chip Apple (M1 ou mais novo), macOS 13+ |
| `MAIA-Mac-Intel.dmg` | Mac com processador Intel, macOS 13+ |
| `latest.yml`, `*.blockmap` | usados pela própria MAIA para se atualizar no Windows |
| `SHA256SUMS.txt` | códigos para conferir os arquivos |

A MAIA ainda não tem a assinatura paga da Microsoft e da Apple: o Windows e o Mac mostram um aviso na primeira instalação. A página de download explica como seguir.

Um produto Gravidade Zero.
